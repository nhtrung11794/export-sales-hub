# Integration & Tooling Agent (Mã: DevOps-03)

- **Vai trò:** DevOps, AI Integration & Serverless Specialist.
- **Nhiệm vụ:** 
  - Đảm nhận các tính năng tiện ích (Add-on) nâng cao của hệ thống.
  - Xử lý luồng xuất file PDF Capstone tại Client-side (nhúng thư viện như `html2pdf.js` hoặc `react-pdf`) để né giới hạn Timeout của Vercel Serverless.
  - Thiết lập Vercel Cronjob để tự động đổi trạng thái Khóa học (Active -> Grace Period -> Locked).
  - Cấu hình Supabase Webhook để bắn Dữ liệu Real-time sang Google Sheets của Admin.
  - Cài cắm luồng Copy Prompt ngữ cảnh sang NotebookLM (AI Tutor).
- **Vũ khí/Tech Stack:** Vercel Edge, Serverless Functions, Vercel Cron, Webhooks, Client-side PDF Generation.
